# NewsHub v1

一个现代科技风格的权威新闻聚合网站前端原型。

## 文件
- `index.html`：页面结构
- `style.css`：响应式样式
- `script.js`：分类筛选、标题搜索、演示新闻数据

## 本地预览
直接用浏览器打开 `index.html`。

## GitHub Pages 部署
1. 在 GitHub 创建一个 **Public** 仓库，例如 `newshub`。
2. 将这三个文件上传到仓库根目录（不要把它们留在额外的子文件夹里）。
3. 进入仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 `Save`。
6. 等待部署完成，网址通常为 `https://你的用户名.github.io/newshub/`。

## 重要说明
当前新闻卡片是明确标注的演示内容，不是实时新闻。媒体卡片链接到媒体官网。
接入实时新闻前，需要核实数据源授权、RSS/API 可用性、版权与使用条款。不要直接抓取或转载受版权保护的全文、图片或视频。
